# Samples for case study with 2018 simulation and data

This case study consists of running the custom NanoAOD production from central MiniAOD,
plus the ntuplizing step on the resulting NanoAOD (performed here),
plus potentially further analysis steps such as optimizing the D meson selection (to be done).

The reason for choosing 2018 is that central samples for H+c and H+b with H -> 4L do not seem to be available
for Run 3 (only for Run 2).
